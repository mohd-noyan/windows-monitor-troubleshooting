## Monitor Detection Troubleshooting
## Project Role
IT Support Technician
## Project Overview
Diagnosed and resolved an external monitor detection issue on a Windows 11 workstation. The monitor was identified in Device Manager but was not functioning correctly due to a driver-related issue.
## Tasks Performed
Inspected Device Manager for monitor status.
Verified monitor recognition under Windows.
Checked display settings and monitor connections.
Updated monitor/display drivers.
Tested monitor functionality after driver installation.
## Issue Identified
The external monitor was detected by the operating system but was not displaying correctly.
## Resolution
Updated the monitor/display driver through Device Manager and restored normal monitor functionality.
## Skills Demonstrated
Windows 11 Administration
Device Manager Troubleshooting
Driver Management
Hardware Support
Monitor Configuration
Technical Problem Solving
## Outcome
Successfully restored monitor operation and verified proper display functionality.
